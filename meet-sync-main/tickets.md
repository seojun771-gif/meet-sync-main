# 티켓 — 약속 잡기 도우미 (프로토타입)

`specs/spec-meetup-planner.md` 를 세로로 잘라 만든 일곱 조각. 한 조각만 끝내도 화면에서 뭔가가 실제로 돌아간다.

**막힌 게 없는 티켓부터 하나씩** 한다. 하나 끝날 때마다 `/clear` 하고 다음으로 간다.

---

## 1. 참여자 한 명 → 시간 한 칸 → 겹치는 시간 한 개

**무엇이 돌아가게 되나:** 파일을 열어 참여자를 두 명 넣고, 탭을 바꿔가며 시간표 칸을 눌러 칠하면 둘 다 되는 시간 한 개가 화면에 뜬다. 새로고침해도 남아 있다. 드래그도 지도도 없다 — 클릭 한 번에 한 칸.

**막고 있는 것:** 없음 — 바로 시작 가능

- [x] Given 저장된 게 하나도 없는 상태에서
      When  파일을 열고 이름 "민수"를 넣어 추가하면
      Then  상단에 민수 탭이 생기고 70칸짜리 빈 시간표가 보인다
- [x] Given 민수와 지훈 두 탭이 있는 상태에서
      When  민수 탭에서 목요일 19시 칸을 누르고, 지훈 탭에서 같은 칸을 누르면
      Then  "목 19시 — 2명" 한 줄이 보인다
- [x] Given 참여자 둘이 같은 칸을 칠한 상태에서
      When  새로고침하면
      Then  탭 두 개와 칠해진 칸, 겹치는 시간 한 줄이 그대로 보인다
- [x] Given 저장된 값이 깨져 있는 상태에서
      When  파일을 열면
      Then  에러 없이 참여자가 한 명도 없는 화면이 보인다

---

## 2. ① 시간 단계 완성 — 드래그와 참여자 관리

**무엇이 돌아가게 되나:** 칸을 하나씩 누르지 않고 드래그로 칠하고 지운다. 날짜 한 줄·시간 한 줄을 통째로도 칠한다. 칠한 칸 수가 보이고, "전부 안 됨"으로 저장한 사람과 아직 입력 안 한 사람이 탭에서 구분된다. 참여자를 지우거나 여섯 명까지 채울 수 있다.

**막고 있는 것:** 1번

- [x] Given 민수 탭에서 시간표가 비어 있는 상태에서
      When  목요일 18시부터 21시까지 세로로 드래그하면
      Then  네 칸이 칠해지고 "4칸 선택"이 보인다
- [x] Given 그 네 칸이 칠해진 상태에서
      When  같은 자리를 다시 드래그하면
      Then  네 칸이 지워지고 "0칸 선택"이 보인다
- [x] Given 참여자가 여섯 명인 상태에서
      When  일곱 번째를 추가하려 하면
      Then  추가되지 않고 여섯 명이 최대라는 안내가 보인다
- [x] Given 민수는 한 칸도 안 칠하고 저장했고 지훈은 아직 저장하지 않은 상태에서
      When  참여자 탭을 보면
      Then  민수는 입력 완료로, 지훈은 미입력으로 다르게 표시된다

---

## 3. 최적 시간 세 개

**무엇이 돌아가게 되나:** 겹치는 시간 하나가 아니라 상위 세 개가 뜬다. 각각 "세 명 중 두 명"과 못 오는 사람 이름이 붙는다. 전원 되는 시간이 없어도 목록이 비지 않는다. 후보 하나를 골라 둘 수 있다.

**막고 있는 것:** 2번

- [x] Given 세 명이 각각 다른 시간만 칠해 전원 겹치는 칸이 없는 상태에서
      When  최적 시간을 보면
      Then  후보 세 개가 각각 "3명 중 2명"과 못 오는 사람 이름과 함께 보인다
- [x] Given 두 후보의 겹친 사람 수가 같은 상태에서
      When  최적 시간을 보면
      Then  날짜가 빠른 쪽이 위에 있다
- [x] Given 아무도 시간을 저장하지 않은 상태에서
      When  최적 시간 자리를 보면
      Then  "아직 입력한 사람이 없습니다"가 보인다
- [x] Given 후보 세 개가 보이는 상태에서
      When  두 번째 후보를 누르면
      Then  그 후보에 선택 표시가 생기고 나머지 둘은 해제된다

---

## 4. 지도 깔고 드래그하기

**무엇이 돌아가게 되나:** ①②③ 단계 전환이 생기고, ② 단계에 진짜 지도가 깔린다. 드래그해서 지도를 옮길 수 있고, 옮긴 위치가 저장된다. 아직 클릭해도 아무 일도 일어나지 않는다 — 이 티켓은 지도가 뜨고 움직이는 것까지다.

**막고 있는 것:** 3번

- [x] Given 시간 후보를 고른 상태에서
      When  ② 장소 단계를 누르면
      Then  상단 단계 표시가 ②로 바뀌고 지도 그림이 화면에 보인다
- [x] Given 지도가 보이는 상태에서
      When  지도를 왼쪽으로 드래그하면
      Then  지도가 따라 움직이고 오른쪽에 새로 드러난 부분이 채워진다
- [x] Given 지도를 드래그해 옮긴 상태에서
      When  새로고침하면
      Then  옮긴 위치 그대로 보인다
- [x] Given 인터넷이 끊긴 상태에서
      When  파일을 열고 ② 단계로 가면
      Then  지도 자리만 비어 있고 화면이 깨지거나 에러가 뜨지 않는다

---

## 5. 출발지 찍기와 중간지점

**무엇이 돌아가게 되나:** 각자 지도를 클릭해 자기 출발지를 찍는다. 두 명 이상이 찍으면 모두의 핀 사이에 중간지점 핀이 다른 모양으로 뜬다. 지도를 드래그해도 핀은 자기 자리에 붙어 있다.

**막고 있는 것:** 4번

- [x] Given 민수 탭이고 지도가 보이는 상태에서
      When  지도의 한 지점을 클릭하면
      Then  그 자리에 민수 핀이 생긴다
- [x] Given 민수 한 명만 출발지를 찍은 상태에서
      When  지도를 보면
      Then  중간지점 핀이 없고 두 명 이상 필요하다는 안내가 보인다
- [x] Given 세 명이 서로 떨어진 곳에 출발지를 찍은 상태에서
      When  지도를 보면
      Then  출발지 핀 세 개와 그 사이에 다른 모양의 중간지점 핀 하나가 보인다
- [x] Given 핀 네 개가 보이는 상태에서
      When  지도를 드래그하면
      Then  핀 네 개가 지도를 따라 움직이고 계속 같은 자리에 붙어 있다

---

## 6. 장소 후보와 직접 추가

**무엇이 돌아가게 되나:** 중간지점에서 가장 가까운 지역의 장소 후보가 카드로 뜬다. 카테고리로 거를 수 있고, 목록에 없는 곳은 이름·카테고리·지도 클릭으로 직접 넣으면 똑같은 카드가 된다.

**막고 있는 것:** 5번

- [x] Given 중간지점이 합정 근처에 찍힌 상태에서
      When  ② 단계 아래쪽을 보면
      Then  "합정" 지역 이름과 후보 카드들이 이름·카테고리·도보 몇 분과 함께 보인다
- [x] Given 후보 카드가 보이는 상태에서
      When  "카페"를 누르면
      Then  카페 카드만 남고 나머지는 사라진다
- [x] Given ② 단계에서
      When  이름 "우동카덴", 카테고리 "맛집"을 넣고 지도를 클릭해 추가하면
      Then  원래 후보와 같은 모양의 카드가 생기고 도보 몇 분이 함께 보인다
- [x] Given 추가 입력창에서
      When  이름을 비운 채 추가를 누르면
      Then  카드가 생기지 않고 이름을 넣으라는 안내가 보인다

---

## 7. 투표와 확정

**무엇이 돌아가게 되나:** 참여자당 한 표를 던지고 옮길 수 있다. 확정하기를 누르면 ③ 단계에 시간·장소·참여자 명단이 나오고, 동점이나 무투표였으면 왜 그렇게 정해졌는지 한 줄이 붙는다. 확정을 취소하거나 전부 지우고 처음부터 다시 시작할 수 있다. **여기까지 하면 명세가 전부 끝난다.**

**막고 있는 것:** 6번

- [x] Given 민수 탭에서 A 후보에 표를 던진 상태에서
      When  민수 탭에서 B 후보를 누르면
      Then  A가 0표, B가 1표가 되고 B 카드에 민수 이름이 보인다
- [x] Given 두 후보가 1표씩인 상태에서
      When  확정하기를 누르면
      Then  ③ 확정 화면에 시간·장소·참여자 명단이 보이고 동점이라 규칙대로 골랐다는 이유가 한 줄 보인다
- [x] Given 아무도 투표하지 않은 상태에서
      When  확정하기를 누르면
      Then  확정 화면이 나오고 아무도 투표하지 않아 자동으로 정해졌다는 이유가 한 줄 보인다
- [x] Given 확정된 상태에서
      When  처음부터 다시 시작을 누르면
      Then  참여자가 한 명도 없는 ① 단계로 돌아간다

# 티켓 — 잇다(ITDA) 팀 매칭 및 완주 신뢰 서비스 MVP

`specs/spec-itda.md` 를 세로로 잘라 만든 여섯 조각.

**막힌 게 없는 티켓부터 하나씩** 한다. 하나 끝날 때마다 `/clear` 하고 다음으로 간다.

---

## 1. 프로필 등록 및 조회

**무엇이 돌아가게 되나:** 사용자가 이름과 학교를 입력해 프로필을 만들고, 자신의 프로필 화면에서 그 정보와 "집계 중" Trust Score 배지를 볼 수 있다.

**막고 있는 것:** 없음 — 바로 시작 가능

- [ ] Given 프로필이 없는 상태에서
      When  이름과 학교를 입력하고 저장 버튼을 누르면
      Then  내 프로필 화면에 입력한 이름과 학교가 보인다
- [ ] Given 프로필을 막 만든 상태에서
      When  내 프로필 화면을 열면
      Then  Trust Score 자리에 "집계 중" 배지가 보인다
- [ ] Given 이름을 입력하지 않은 상태에서
      When  저장 버튼을 누르면
      Then  저장되지 않고 이름을 입력하라는 안내가 보인다

---

## 2. 팀 스페이스 생성 + 초대 + 수락/거절 (마감일 포함)

**무엇이 돌아가게 되나:** 프로필이 있는 사용자가 마감일이 있는 팀 스페이스를 만들고 다른 사람을 초대하면, 상대가 수락하거나 거절할 수 있다.

**막고 있는 것:** 1번

- [ ] Given 프로필이 있는 상태에서
      When  팀 스페이스 이름과 마감일을 입력하고 만들면
      Then  팀 스페이스 상세 화면에 이름과 마감일이 보인다
- [ ] Given 만든 팀 스페이스가 있는 상태에서
      When  팀원을 초대하고 상대가 수락하면
      Then  팀 스페이스 팀원 목록에 그 사람이 추가된다
- [ ] Given 초대를 받은 상태에서
      When  거절을 누르면
      Then  팀 스페이스 팀원 목록에 추가되지 않는다

---

## 3. 팀 스페이스 목록 화면

**무엇이 돌아가게 되나:** 참여 중인 여러 프로젝트를 목록에서 한눈에 보고, 하나를 눌러 상세 화면으로 들어갈 수 있다.

**막고 있는 것:** 2번

- [ ] Given 참여 중인 프로젝트가 2개 있는 상태에서
      When  팀 스페이스 목록 화면을 열면
      Then  두 프로젝트 이름이 목록에 보인다
- [ ] Given 참여 중인 프로젝트가 하나도 없는 상태에서
      When  팀 스페이스 목록 화면을 열면
      Then  참여 중인 프로젝트가 없다는 안내가 보인다
- [ ] Given 참여 중인 프로젝트가 있는 상태에서
      When  목록에서 프로젝트 하나를 누르면
      Then  그 프로젝트의 상세 화면(팀원 목록)이 보인다

---

## 4. 완주 판정 (전원 동의 + 7일 자동 확정)

**무엇이 돌아가게 되나:** 마감일이 지난 뒤 팀원 전원이 완료를 확인하면 "완주" 상태가 되고, 확인이 늦어져도 7일이 지나면 시스템이 자동으로 완주 처리한다.

**막고 있는 것:** 2번

- [ ] Given 팀 스페이스의 마감일이 지난 상태에서
      When  팀원 전원이 "완료" 버튼을 누르면
      Then  팀 스페이스 상태가 "완주"로 바뀐다
- [ ] Given 마감일이 지났지만 팀원 중 한 명이 완료 확인을 안 한 상태에서
      When  마감일로부터 7일이 지나면
      Then  팀 스페이스 상태가 자동으로 "완주"로 바뀐다
- [ ] Given 마감일이 아직 지나지 않은 상태에서
      When  완료 버튼을 누르면
      Then  완료 버튼이 눌리지 않는다

---

## 5. 블라인드 상호평가

**무엇이 돌아가게 되나:** 완주 처리된 프로젝트의 팀원들이 서로를 평가하되, 전원이 제출하기 전까지는 서로의 점수·코멘트를 볼 수 없다.

**막고 있는 것:** 4번

- [ ] Given 팀 스페이스가 "완주" 상태인 상태에서
      When  팀원 한 명이 다른 팀원에게 별점과 코멘트를 남기면
      Then  그 평가가 저장되지만 아직 다른 팀원에게는 보이지 않는다
- [ ] Given 팀원 중 일부만 평가를 제출한 상태에서
      When  아직 제출 안 한 팀원이 있는 채로 평가 화면을 열면
      Then  다른 사람의 점수나 코멘트가 보이지 않는다
- [ ] Given 팀원 전원이 평가를 제출한 상태에서
      When  평가 결과 화면을 열면
      Then  모든 팀원의 점수와 코멘트가 보인다

---

## 6. Trust Score 계산 및 프로필 표시

**무엇이 돌아가게 되나:** 완주·평가 데이터가 쌓이면 프로필의 Trust Score가 실제 가중치 공식으로 계산되어 갱신되고, 데이터가 적으면 "집계 중"으로 표시된다. **여기까지 하면 명세가 전부 끝난다.**

**막고 있는 것:** 5번

- [ ] Given 평가가 2회만 쌓인 상태에서
      When  프로필 화면을 열면
      Then  Trust Score 자리에 "집계 중" 배지가 보인다
- [ ] Given 평가가 3회 이상 쌓인 상태에서
      When  프로필 화면을 열면
      Then  완주율 40%·마감준수율 25%·동료평가 25%·최근활동 10% 가중치로 계산된 점수가 보인다
- [ ] Given 완주 처리된 프로젝트가 하나 더 추가된 상태에서
      When  프로필 화면을 새로고침하면
      Then  Trust Score 점수가 갱신되어 보인다
