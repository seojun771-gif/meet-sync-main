## 1. 문제 정의

**“언제”와 “어디서”가 서로 다른 채널에 흩어져 있다.**
정기적 모임이 없는 그룹일수록 이 조율 피로가 매번 반복된다.

| # | 문제 | 부연 |
|---|---|---|
| 1 | 시간은 카톡 투표, 장소는 지도 앱 | 채널이 나뉘어 앱을 계속 오가야 한다 |
| 2 | 3명만 모여도 시간 조율부터 부담 | 시간이 정해져도 장소에서 또 막힌다 |
| 3 | 확인 누락으로 30분~1시간 지각 | 소모임 앱을 써도 확정까지 4일 |
| 4 | “누가 더 멀리 오나” 눈치싸움과 불공평함 | 장소를 정할 때마다 반복되는 마찰 |

## 2. 서비스 소개

1. **시간 조율** — 각 참여자가 가능한 시간대 입력 → 최적 시간대 자동 추천
2. **중간 지점 계산** — 각자 출발지 입력 → 중간 지점 자동 계산
3. **장소 추천** — 중간지점 반경 내 카테고리별 장소들 추천
4. **투표 자동 확정** — 최다 득표로 확정, 동점/무투표시 가장 가까운 일정으로 선정

## 3. 시장 / 경쟁 분석

| 유형 | 대표 서비스 | 한계 |

## 6. 사용자 시나리오

**기본 플로우: 링크 하나로 시간 ~ 장소 확정 까지**

```
챗봇 초대 / 링크 공유
  → 시간 입력 · 최적 시간 추천
  → 출발지 입력 · 중간 지점 계산
  → 장소 추천 · 투표
  → 최종 확정
```

- **예외 1 · 중도 합류/이탈**: 같은 링크로 자동 배정, 실시간 재계산 (방장 초대 불필요)
- **예외 2 · 투표 동점/무투표**: 동점 시 가장 가까운 일정으로 선정, 무투표시 마감 1시간 전 자동 확정

## 7. User Flow Chart

```
[방장 챗봇 추가]
  → [챗봇: 약속 링크 공유]
  → [방장: 약속명, 목적, 인원 입력 → UUID 참여 링크 생성]
  → <카카오 시작하기>
        ├→ 비회원 참여자 (닉네임만 입력 후 참여)
        └→ 회원 참여자 (카카오 로그인)
  → [참여자 가능 시간 + 출발지 입력]
  → <모두 입력 완료?>
  → <참여 인원 변동/취소> → [멤버 재조정 & 취소자 데이터 제외] ↺
  → [시스템 최적의 시간 추천 + 중간 지점 계산]
  → [참여자 추천 장소에 투표]
  → <투표 마감 시 동점 or 무투표>
        ├→ [최다 득표 장소/시간으로 확정]
        └→ [가장 가까운 일정]
  → <참여자가 회원인가?>
        ├→ 회원: 앱 푸시 / 알림톡 발송
        └→ 비회원: 웹 결과 페이지 URL 생성
  → End
```

## 8. 기대 효과

| 시간 조율 피로 감소 | 진입장벽 완화 | 장소 갈등 해소 |
|---|---|---|
| 여러 채널을 링크 하나로 통합, 확인 누락에 따른 피로 감소 | 비회원 참여로 신입·일회성 참여자도 로그인 부담 없이 즉시 합류 | 출발지 기반 중간지점 자동 계산으로 눈치싸움·정서적 마찰 제거 |

## 9. MVP

**“약속생성 → 시간조율 → 중간지점·장소추천 → 투표” 까지 완결**

### ✅ 범위 내 (MVP)
- 링크 기반 비회원 참여
- 시간 조율 · 최적 시간 추천
- 중간 지점 계산
- 기본 장소 추천 (카카오맵 · 카테고리 필터)
- 장소 투표 · 자동 확정

### → 범위 외 (v2 확장)
- AI(LLM) 기반 장소 추천
- 캘린더 등록 · 리마인드 알림
- 반복 모임 관리 · 정산
- 예약 연동 (캐치 테이블 등)

## 10. 기술 실현 가능성 검토

**핵심 기능은 낮은 난이도. 웹 기반 링크 공유형이 현실적 — 아직 더 검토 필요**

| 난이도 | 기능 | 구현 방법 |
|---|---|---|
| 낮음 | 시간 조율 | 캘린더 UI + 가능시간 겹침 계산 |
| 낮음 | 위치 입력 · 좌표 변환 | 주소 → Geocoding API 좌표변환 |
| 낮음 | 중간 지점 계산 | 초기 좌표 평균(centroid) 방식 |
| 중간 | 장소 추천 | 장소 검색 API, 카테고리 필터로 보완 |
| 낮음 | 투표 · 자동 확정 | 단일 선택 투표 + 마감 확정 규칙 |

## 12. 와이어프레임 (3화면)

### 화면 1 — 가능한 시간 입력 (드래그 테이블)
- 세로 = 시간(12시~22시), 가로 = 날짜(토9 / 일10 / 월11 / 화12 / 수13 / 목14)
- “되는 칸을 드래그하거나 탭해서 칠하세요. 한 번 더 쓸면 지워집니다.”
- 툴바: `칠하기` `지우기` `행 전체` `열 전체`
- 좌우로 밀면 8/15 까지
- 안내: 비어 있으면 「전부 안 됨」으로 제출 가능 — 미입력자와 구분해야 마감 계산이 정확해짐
- 하단 CTA: **12칸 선택 · 저장**

### 화면 2 — 중간장소 결과 보기
- 지도 위 “우리 사이 중간장소” 핀 + 참여자별 핀 (은평에서 33분 / 강남에서 35분 / 영등포에서 31분)
- 결과: **합정역 (한옥거리) 25분** (평균 이동 시간), `길찾기`
  - 1: 33분 · 지하철 / 2: 35분 · 자차 / 3: 31분 · 지하철 / 편차 4분 · 수평해요
- 하단 CTA: **★ 여기서 뭐하지?**

### 화면 3 — 장소 추천 (여기에서 뭐하지?)
- “합정역 근처에서 여기 가보는 건 어때요?”
- 카테고리 탭: `맛집` `카페` `술집` `놀거리`
- 카드 리스트: 이름 / 분류 · 도보 n분 · ★평점 / 현재 득표수 / 투표 버튼
  - 우동 카덴 — 일식 · 도보 4분 · ★4.5 · 3표
  - 해피베어데이 — 디저트카페 · 도보 6분 · ★4.3 · 2표
  - 합정 상미집 — 한식 · 도보 8분 · ★4.6 · 0표
- 하단: `직접 추가` / (확정 버튼)
