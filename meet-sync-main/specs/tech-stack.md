# 기술 스택

## 무엇으로 만드는가

- **HTML + CSS + JavaScript** 만 쓴다
- 파일은 **`index.html` 한 개**. CSS와 JavaScript는 그 안에 넣는다
- 데이터는 브라우저의 **`localStorage`** 에 저장한다
- 서버, 데이터베이스, 로그인은 만들지 않는다

## 왜 이렇게 정했는가

- **파일 하나면 더블클릭으로 열린다.** 친구에게 보내도 그냥 열린다
- **설치할 것이 없다.** 인터넷이 끊겨도 돌아간다
- **3일 안에 완성할 수 있는 유일한 크기다**

## 절대 하지 않는 것

- 라이브러리·프레임워크를 쓰지 않는다 (React, Vue, jQuery, Tailwind, Bootstrap …)
- 빌드 도구를 쓰지 않는다 (npm, webpack, vite …)
- **데이터를 가져오는 외부 호출은 하지 않는다** (`fetch`, XHR, 지오코딩 API, 장소 검색 API …)

## 예외적으로 허용하는 것

- **외부 이미지**를 불러올 수 있다 (지도 타일, 장소 사진 등)
- **외부 폰트**를 불러올 수 있다

> 이미지·폰트까지만이다. 좌표나 장소 목록 같은 **데이터**는 여전히 코드 안에 넣는다.

## 코드 규칙

- 변수명과 함수명은 **영어로** 쓴다. 한글 발음을 알파벳으로 적지 않는다 (`gwamok` ✕)
- 저장소 키 이름은 **하나로 통일**한다. 여러 개로 나누지 않는다
- 저장된 값이 없거나 깨져 있으면 **빈 화면으로 조용히 시작한다.** 에러 팝업을 띄우지 않는다
- 날짜는 항상 `YYYY-MM-DD` 문자열로 다룬다
